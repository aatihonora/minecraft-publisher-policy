Privacy Policy

Effective date: 20 November 2026 · Last updated: 20 November 2026

This Privacy Policy describes how the personal Minecraft Publisher software project (“Software”) handles information. The Software is intended to run locally on the operator’s Windows computer using Docker. It is not designed as a public, multi-user service. This policy describes the standard local configuration; it must be revised if the Software is later hosted remotely or connected to additional services.

1. Operator and contact

Operator: Individual project owner

2. Information handled by the Software

  • TikTok OAuth information: if TikTok is connected, the Software receives OAuth access and refresh tokens and an account identifier returned by TikTok. These are used to authenticate authorized API requests. They are stored in a local SQLite database in the application’s data folder.
  • Local video and caption files: videos placed in the configured folders, associated text caption files, and downloaded source files that the operator is authorized to use.
  • Processing metadata: filenames, source URLs entered by the operator, clip titles and part numbers, processing metadata, queue status, timestamps, publishing identifiers and error messages.
  • Configuration and logs: application settings and operational logs needed to run and troubleshoot the Software. The operator should not put secrets or sensitive personal information into filenames, captions or source lists.

3. Purposes of processing

The Software handles this information to connect to the operator’s authorized TikTok account, manage local video files, create clips with video-processing tools, maintain a local queue, submit authorized API requests when configured, and diagnose errors. The Software does not need or request the operator’s TikTok password.

4. Local storage and Docker

In the standard Windows Docker configuration, the SQLite database is stored in the local project’s data folder, and video files are stored in folders mounted from the local project directory. The operator controls these files and is responsible for access permissions, device security and backups. Docker itself runs the application locally; using Docker does not automatically mean that application data is uploaded to a cloud service.

5. Sharing with third parties

When TikTok integration is used, relevant OAuth tokens and video content are transmitted to TikTok through TikTok’s APIs to carry out authorized functions. If the operator uses YouTube URLs or other external sources, requests are made to those providers to retrieve information or media. Those providers process information under their own terms and privacy policies. The operator should review the policies of each service they connect.

The personal project does not operate an advertising business and does not sell the operator’s personal information. This statement does not describe data practices of TikTok, YouTube, Docker, hosting providers or other third parties.

6. Retention and deletion

SQLite records and OAuth tokens remain in the local database until the operator deletes them or removes the application data. Video files and generated clips remain in their configured local folders until moved or deleted. To remove local application data, stop the Docker application and delete the project’s data folder and any video folders the operator no longer wants to retain. Make any desired backup first.

Deleting local tokens does not necessarily revoke the app’s authorization with TikTok. The operator should also revoke the application’s access through TikTok account settings where that option is available.

7. Security

The operator is responsible for securing the Windows device, Docker environment, local folders, backups and network. Keep the dashboard bound to localhost; do not expose it to the public internet without appropriate authentication and HTTPS. Keep the .env file, SQLite database, client secret and OAuth tokens private. No storage or transmission method is completely secure.

8. International processing

Third-party platforms may process information in countries other than the operator’s country under their own terms and privacy notices. The Software operator does not control those providers’ independent processing.

9. Privacy rights and requests

Depending on applicable law, individuals may have rights to access, correct, erase, restrict or object to processing of personal information. Since the standard application is operated locally by its user, the user can inspect and delete local files and database records directly. Privacy questions can be sent to the contact below.

10. Children

The Software is not designed to collect personal information from children. Do not use it to process another person’s personal information without an appropriate legal basis and any required permissions.
